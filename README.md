# *Minimalistic Applications*
## Application: Portable IP Lookup

**Description:**
A minimalistic PowerShell GUI that works out of the box. Is able to look up both IPv6 and IPv4 IP addresses.

**Customizable:**
```plaintext
#-------------------------------------------------------#
  http://ip-api.com/json/$IPaddress = URL
#-------------------------------------------------------#
```
- Change http://ip-api.com/json/ to the URL desired
- Relocate $IPaddress to the proper location in the URL
